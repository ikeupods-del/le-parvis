# Parvis

Application web chrétienne, gratuite et sans publicité : verset du jour, plans de lecture, carnet de prière, salons, Mon église, maraudes.

- `index.html` : application (pour l'instant, le prototype tel quel).
- `reference/prototype-v1.html` : copie intacte du prototype d'origine, gardée comme référence.
- `.github/workflows/deploy.yml` : déploiement automatique sur GitHub Pages à chaque envoi sur `main`.

## Lancer en local

```bash
npm install
npm run dev
```

Aucun secret dans ce dépôt : voir `.env.example`.
